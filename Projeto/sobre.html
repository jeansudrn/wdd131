Sobre o Projeto

O Grana Cash nasceu como um projeto prático de desenvolvimento web. Seu propósito fundamental é alinhar as diretrizes de acessibilidade e usabilidade para entregar um produto digital que faça sentido na rotina de qualquer cidadão.

A interface foi construída seguindo as melhores práticas visuais do mercado atual, respeitando rigorosamente os critérios de proximidade de itens e o contraste de leitura para públicos de variadas idades.

Desenvolvimento e Postura Profissional

Este site reflete a aplicação prática de engenharia frontend e boas práticas de desenvolvimento web. O projeto foi executado seguindo o cronograma planejado, demonstrando capacidade de organização, gerenciamento de tempo e cumprimento de prazos reais de entrega.

Tecnologias Utilizadas:

  • HTML5 Semântico: Estruturação limpa baseada em padrões de acessibilidade.
  • CSS3 Moderno: Layout responsivo baseado na metodologia mobile-first, sem linhas de código desnecessárias ou duplicadas.
  • JavaScript ES6+: Lógica do sistema responsável pelo processamento de dados, controle de eventos e armazenamento seguro no navegador via localStorage.
